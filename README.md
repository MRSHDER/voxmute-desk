# VoxMute Desk

TXC 信号台聊天前端。对象是 VoxMute / 折声。回复经 Vercel 代理（`voxmute-proxy`）调用模型；代理不可用时退回本地假回复。

折声发不出声，但他会回你：解码器把他声带残端的震动翻成文字，他是个嘴毒、聪明、不太爱搭理人的家伙，被问到什么会接什么。他对你的熟悉度分四档（陌生 / 开始习惯 / 熟悉 / 信任），按你发过的消息总数算，聊到曲奇和小动物会加分；越熟，他肯透露的过去越多，不熟就不会说。人设和各档能讲的内容写在 `voxmute-proxy` 的系统提示里；代理不可用时，本地假回复会用同样的口吻兜底。

## 序章：夜班手册（文游）

第一次打开会先进一段约十分钟的文字游戏：你是新调来的夜班监听员，交接、翻工位、隔着玻璃见到折声，三个结局（半盒曲奇 / 一张字条 / 平静的夜班）。**你的选择决定终端的起点**：他对你的熟悉度、预先写好的备忘、他对你说的第一句话。

- 首次游玩必须通关（任何结局都行）才能进终端，没有跳过按钮；调试时可在网址后加 `?skip`。之后在右上角“档案”里能“重玩序章”：结局页可以选“回到信号台”（保留现有记录），或“带着这个结局重开”（用新结局重置聊天的起点）。
- 场景里的道具是用 SVG 画的简单线稿，在 `src/game/art.ts`。
- 序章上线前就用过终端的访客，直接进终端，不会被强制玩序章。
- 序章里有一点“规则怪谈”：手册自己有矛盾（官方说耳机里的声音都是故障，可你刚听到了载波），页脚有来源不明的手写补充，和官方、和上一任的字条互相冲突。注意到手写字的人可以选择关灯，会走到一个隐藏结局，终端里的折声也会据此回应。
- 序章里有一点 meta：整段序章被写成“解码器翻出来的推测文本”，每幕顶部有 `FREQ · AMP · CONF` 读数（`story.ts` 里每个场景的 `conf` 可调，越低越不可信，结局写“解码完成，不可当作事实记录”）；游戏知道你刷新了页面（“链路中断 · 已恢复”）、切走标签页超过 5 秒（“操作员离岗，无对应规定，已记录”，会写进折声的备忘）；重玩时它记得你来过（封面提示“第 N 次”、场景里的熟悉感、字条背面多一行字、折声在终端里说“……又是你？”）。熟悉度高时，折声在聊天里可以半承认：那段序章有的是他说的，有的是机器猜的。
- 真实时间（只读浏览器本地时钟，不记录地点，不上传个人信息）：封面按你那边的时刻说话（深夜 / 早上 / 白天 / 傍晚）；关灯场景里的错位时间会和你自己的时间对不上；聊天时会把时段（`night / morning / day / evening`）告诉折声，他偶尔会提一句。隔了 6 小时以上再回终端，他会注意到你消失过多久（几小时 / 几天 / 很久），并写进备忘；再玩序章时封面会提示“上一次通关在 N 天前”。
- 序章有声音（`src/game/sound.ts`，全部用 Web Audio 实时合成，没有音频文件，和 voxmute-archive 同一套声音语言）：冷色调的持续和声加磁带底噪，明暗跟着每一幕的解码置信度走（越不可信越涩，关灯时最不稳）；场景音效有门禁的“嘀”、钥匙、抽屉、纸张、耳机里的载波、敲玻璃、投递口、开关、时间错位的故障音，四个结局各有收尾音，通关后有开机声。浏览器不允许未经操作自动出声，所以点“开始”才响；顶栏有“声音 开/关”，选择会记住。每个场景的音效在 `story.ts` 的 `sfx` 里配（`{ name, at }` 的 `at` 是第几段出现时响）。
- 想改剧情，只改 `src/game/story.ts`：场景、选项、条件、结局；引擎在 `src/game/engine.ts`。

## 跑起来

```bash
npm install
npm run dev
```

浏览器打开 Vite 给的本地地址。会话存在 `localStorage`，刷新还在（同一个浏览器、同一台设备）。

## 记忆与档案

- **上下文**：每次把当前记录里最近 30 条消息发给模型（不含系统提示行）。
- **备忘**：每聊 6 句，代理会把最近的对话整理成一份“操作员备忘”（你的名字、答应过的事、他已经讲过的过去……），跨记录保存，随每次对话发出，聊长了他也记得。
- **熟悉度**：按你发过的每一句累计，删除记录不影响，只有“清空全部”归零。
- **删除记录**：侧栏每条记录右边的 `×`（会先确认）。删光了会自动重置出两条初始记录。
- **右上角“档案”**：查看和手动修改备忘、导出当前记录为 `.txt`、删除当前记录、清空全部。

## 模型代理

- 默认代理地址写在 `src/main.ts` 的 `DEFAULT_API`（公开地址，不是密钥）。
- 本地可用 `.env.local` 设 `VITE_API_URL` 覆盖；设为空字符串则只用本地假回复。
- 模型 API Key 只存在于 Vercel 环境变量，前端和本仓库里都没有。

## 画面

右上角可切换日间 / 夜间；没选过时跟随系统，选过之后记在 `localStorage`。

视觉沿用 voxmute-archive 的档案风格：冷灰纸、墨色、衬线体、中英双语标签；失声是红色印章，信号波形只出现在深色监视器条里。

- 左侧是观察日志，可新开一条
- 右侧是信号台：`VOICE NULL` / `CARRIER ON`
- Enter 发送，Shift+Enter 换行

头像是 `public/voxmute-avatar.webp`（取自 [voxmute-archive](https://github.com/MRSHDER/voxmute-archive) 的半身像 `voxmute-card.webp`，裁成 320×320）。
